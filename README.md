# HR Employee Analytics Dashboard

An end-to-end Data Analytics project that analyzes HR employee data to identify workforce patterns, salary trends, employee attrition, and relationships between different employee attributes.

The project includes data cleaning, exploratory data analysis (EDA), data visualization, and an interactive Streamlit dashboard.

---

## 🚀 Features

* Employee workforce analysis
* Salary analysis
* Attrition analysis
* Experience vs Salary analysis
* Correlation analysis
* Interactive filters for Department, Gender, and Attrition Status
* Interactive Streamlit dashboard

---

### 📌 Overview

### 👥 Workforce Analysis
